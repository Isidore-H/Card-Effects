超丝滑的卡片动画，卡片会随着滚动滑出、漂浮、翻转展示内容

基于 Html、Css、Javascript、Vite、UnoCSS、GSAP 和 Lenis。

---

#### 开发

1. git clone 拉源码
2. pnpm install 安装依赖
3. pnpm dev 启动本地开发服务

#### 构建

1. pnpm build 打包生产版本
2. pnpm preview 预览构建结果

#### 项目已部署到 GitHub Pages

1. 页面地址为 https://isidore-h.github.io/Card-Effects/

#### 样式说明

1. 通用布局、颜色、排版已迁移到 UnoCSS 原子类
2. 复杂动画、3D 翻转和关键帧仍保留在 [styles.css](styles.css)
3. UnoCSS 主题配置位于 [uno.config.ts](uno.config.ts)
